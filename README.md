# Naładuj mapę Polski – fork portalu dane.gov.pl

Fork otwartego kodu portalu dane.gov.pl (https://dane.gov.pl/source-code/, wersje `backend_latest` i `frontend_latest` pobrane 21.11.2026) rozbudowany o moduł danych o defibrylatorach AED (HackNation 2026, „Misja AED – dane na ratunek”).

- `backend/` – backend portalu (Django, `mcod`)
- `frontend/` – frontend portalu (Angular)

Pierwszy commit w repozytorium zawiera nietknięty kod portalu; wszystkie zmiany projektu są w kolejnych commitach.
