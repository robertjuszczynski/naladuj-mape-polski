# Klikalny prototyp – Naładuj mapę Polski

Otwórz `index.html` w dowolnej przeglądarce (podwójne kliknięcie). Działa bez internetu i bez instalacji.

- Klikaj w przyciski i linki na ekranach, tak jak w prawdziwym portalu. Kliknięcie obok podświetli klikalne miejsca.
- Strzałki ← → na klawiaturze (albo mała pigułka w prawym dolnym rogu) przełączają ekrany.
- „Instrukcje” w pigułce: „[Opcjonalne] Instrukcje jak otworzyć projekt” – adres działającego portalu, konta demo i scenariusz testu.

Zrzuty w `ekrany/` pochodzą z działającego portalu (fork dane.gov.pl z modułem AED), 22.11.2026.
